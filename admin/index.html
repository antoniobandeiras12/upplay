Sobre as métricas do aplicativo

Este painel registra métricas estritamente coletadas no site e na rota /download. Instalações efetivas e usuários ativos dentro do aplicativo só aparecerão caso seja implementada uma telemetria nativa dentro do próprio build do APK. Nunca apresentamos números simulados.

Privacidade e Retenção

Nenhum endereço IP completo é exposto no painel ou mantido em texto claro nos relatórios. Os identificadores são hashes anônimos e os registros brutos possuem retenção configurada para limpeza periódica automática.
