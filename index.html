Dúvidas Frequentes

Perguntas sobre funcionamento, compatibilidade e instalação.

O que é a instalação via APK?
O APK é o formato de pacote nativo do sistema Android. Ele permite instalar o aplicativo diretamente no aparelho sem passar por lojas de aplicativos, mantendo total integridade do instalador original.
A UpPlay funciona em TV Box ou Smart TV?
Sim. O aplicativo é compatível com dispositivos de TV Box e televisores que operam com o sistema operacional Android TV, funcionando com controle remoto convencional.
Qual a conexão de internet recomendada?
Para reprodução contínua e sem oscilações em alta resolução, recomenda-se uma conexão de banda larga estável a partir de 15 Mbps.
Como atualizar o aplicativo para novas versões?
Quando houver uma nova atualização, a própria interface exibirá um aviso para atualização direta, ou você poderá baixar a versão mais recente aqui na página oficial.
